# 图标为什么是一整块纯洋红

这两张图（`icon.png` 14×14、`icon@2x.png` 28×28）是本项目自己生成的，不是从别处拿的。

颜色是刻意挑的 **#FF00FF（纯洋红）**，而且整张填满，理由只有一个：

**文档里那个「判分」按钮是画在画布上的，不是 DOM 元素。** 编辑器把内容控件的边框、
标签和挂在上面的按钮一起画进 canvas，DOM 里按文字或按背景图去找，找到的永远是零个。
自动化要点它，只能在画布像素里找——所以图标必须是一个**正文里绝不会出现的颜色**，
找它才是确定的，而不是靠估行高、估偏移。

估坐标那条路我们走过：在标签那一行上打了一整块网格，一个点都没点着；
换成按颜色找像素，第一次就点着了。

⚠ 改这个颜色的话，`demo/e2e/run.mjs` 里的 `ICON_RGB` 要跟着改，否则那条验收会报
「按钮没被画出来」——而按钮其实好好的。
