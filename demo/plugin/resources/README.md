# Why the icon is a solid block of pure magenta

> English | [中文](README.zh.md)

These two images (`icon.png` 14×14, `icon@2x.png` 28×28) were generated by this project itself, not taken from anywhere else.

The color was deliberately chosen as **#FF00FF (pure magenta)**, filling the entire image, for one reason only:

**The `判分` ("grade") button in the document is drawn on the canvas; it is not a DOM element.** The editor draws the content control's border,
its label and the button attached to it into the canvas together, so searching the DOM by text or by background image always finds zero elements.
For automation to click it, the only way is to search the canvas pixels, so the icon must be **a color that never appears in body text**;
only then is finding it deterministic, instead of relying on guessed line heights and guessed offsets.

We tried the coordinate-guessing route: we clicked a full grid of points over the label row and did not hit it once;
after switching to finding the pixels by color, it hit on the first try.

⚠ If you change this color, `ICON_RGB` in `demo/e2e/run.mjs` must be changed to match; otherwise that acceptance test will report
`按钮没被画出来` ("the button was not drawn"), while the button is actually fine.
